A structured guide to mastering Collectors, Grouping, and Sorting.

Basic Gender Grouping

Question 01

Given an employee collection, find the gender count using a standard groupingBy collector.


Map<String, Long> genderDetails = employees.stream()
    .collect(Collectors.groupingBy(
        Employee::getGender, 
        Collectors.counting()
    ));

genderDetails.forEach((k, v) -> System.out.println(k + " : " + v));

Explicit Map Implementation

Question 02

Specify a HashMap as the target collection type during the grouping process.


HashMap<String, Long> genderDetails = employees.stream()
    .collect(Collectors.groupingBy(
        emp -> emp.getGender(),
        HashMap::new,
        Collectors.counting()
    ));

Sorting & LinkedHashMap

Question 03 & 04

Sort employees by rating (descending) and capture the result in a LinkedHashMap to preserve order.


LinkedHashMap<String, Double> empRating = employees.stream()
    .sorted(Comparator.comparingDouble(Employee::getRating).reversed())
    .collect(Collectors.toMap(
        Employee::getName, 
        Employee::getRating, 
        (oldValue, newValue) -> oldValue, 
        LinkedHashMap::new
    ));
