In-Order Traversal (Recursive)

DFS Traversal

Logic: Left -> Root -> Right.

public class BinaryTree {
    Node root;	
    public BinaryTree() { this.root = null; }	
    public void printInOrder() { printInOrderRecursive(root); }
    private void printInOrderRecursive(Node node) {
        if (node == null) return;
        printInOrderRecursive(node.left);
        System.out.println(node.data);
        printInOrderRecursive(node.right);
    }
}
Complexity: Time: $O(n)$ | Space: $O(h)$

Level Order Traversal (Iterative)

BFS Traversal

Logic: Visits nodes level-by-level using a Queue (FIFO).

private List<Integer> levelOrderTraversal(Node root) {
    List<Integer> levelOrder = new ArrayList<>();
    if (root == null) return levelOrder;
    Queue<Node> queue = new LinkedList<>();
    queue.add(root);
    while (!queue.isEmpty()) {
        final Node current = queue.poll();
        levelOrder.add(current.data);
        if (current.left != null) queue.add(current.left);
        if (current.right != null) queue.add(current.right);
    }
    return levelOrder;
}
Complexity: Time: $O(n)$ | Space: $O(w)$ (Max Width)

Module: Binary Search Tree

BST Insertion (Recursive)

BST Operations

Logic: Recursively traverse to find the correct position. Smaller values go left, larger values go right.

public void insert(int key) {
    root = insertRecursive(root, key);
}

private Node insertRecursive(Node current, int key) {
    if(current == null) {
        current = new Node(key);
        return current;
    }
    if(key < current.data) {
        current.left = insertRecursive(current.left, key);
    } else if(key > current.data) {
        current.right = insertRecursive(current.right, key);
    }
    return current;
}
Complexity: Time: $O(h)$ | Space: $O(h)$

Guess the Output: Break in forEach

Syntax Logic

Observe the code below. Will it compile? If so, what is the output?

List<Integer> numList = List.of(1, 2, 3, 4);

numList.forEach(num -> {
    System.out.println(num);
    // Guess what happens if the following code executes:
    break; 
});
Solution: This code will not compile. The break keyword can only be used inside loops (for, while) or switches. A lambda expression is a function, not a loop!

Module: Thread Interruption Logic

Interruption Best Practice

Multithreading

This example demonstrates the "Double Defense" strategy: checking for interrupts during active logic (isInterrupted) and handling blocking calls (sleep).

public class SimpleInterruptDemo {
    public static void main(String[] args) throws InterruptedException {
        Thread worker = new Thread(() -> {
            for (int i = 0; i < 10; i++) {
                // 1. MANUAL CHECK: For active business logic
                if (Thread.currentThread().isInterrupted()) {
                    System.out.println("Worker: The flag was manually inspected and stopping at :" + i);
                    return; // Graceful exit
                }

                System.out.println("count :" + i);

                try {
                    // 2. BLOCKING CALL: JVM automatically checks flag here
                    Thread.sleep(1000);
                } catch (InterruptedException e) {
                    System.out.println("Worker interruption handled. Propagating signal...");
                    // GOLDEN RULE: Restore the interrupt status
                    Thread.currentThread().interrupt();
                    return; // Without return, thread would continue 'zombie' style
                }
            }
        });

        worker.start();
        Thread.sleep(3500); // Let it run briefly

        System.out.println("Main: Interrupting worker...");
        worker.interrupt();
        System.out.println("Main Thread execution completes.");
    }
}

Module: Volatile Examples

Example 1: Volatile Shutdown

Thread Signaling 
public class VolatileShutdown {
    private static volatile boolean active = true;

    public static void main(String[] args) throws InterruptedException {
        Thread t1 = new Thread(() -> {
            long count = 0;
            System.out.println("Worker: Starting loop...");
            while(active) {
                System.out.println(count++);
            }
            System.out.println("Worker:completes");
        });

        t1.start();
        Thread.sleep(100);
        active = false;
        t1.join();
        System.out.println("main program exit");
    }
}

Example 2: Volatile Status

Visibility Guarantee 
public class VolatileStatus {
    // Volatile ensures Thread 1 sees the updates made by Thread 2 immediately
    private static volatile String status = "INITIALIZE";

    public static void main(String[] args) {
        // Worker 1: The Observer
        Thread t1 = new Thread(() -> {
            System.out.println("Worker 1: Waiting for FINISH...");
            while (!status.equals("FINISH")) {
                // Spinning until status changes in Main Memory
            }
            System.out.println("Worker 1: Detected FINISH! Execution completed.");
        });

        // Worker 2: The Updater
        Thread t2 = new Thread(() -> {
            try {
                Thread.sleep(1000);
                status = "PROCESSING";
                Thread.sleep(1000);
                status = "FINISH";
            } catch (InterruptedException e) {
                e.printStackTrace();
            }
        });

        t1.start();
        t2.start();
    }
}

Structural: Adapter Pattern

Converts the interface of a class into another interface clients expect.

Payment System Integration

Adapter 
public interface PaymentProcessor {
    void processPayments(String customerName, double amount);
}

class LegacyBankAPI {
    public void performWireTransfer(String bankCode, String accountName, String value) {
        System.out.println("Legacy Bank transferring " + value + " for " + accountName);
    }
}

public class BankAdapter implements PaymentProcessor {
    private LegacyBankAPI legacyBankAPI;
    public BankAdapter(LegacyBankAPI legacyBankAPI) { this.legacyBankAPI = legacyBankAPI; }

    @Override
    public void processPayments(String name, double amount) {
        String value = String.valueOf(amount);
        legacyBankAPI.performWireTransfer("CODE_99", name, value);
    }
}

public class PaymentService {
    public static void main(String[] args) {
        LegacyBankAPI old = new LegacyBankAPI();
        PaymentProcessor payment = new BankAdapter(old);
        payment.processPayments("John", 450.00);
    }
}

Structural: Decorator Pattern

Dynamic Notification System

Decorator 
public interface Notifier { void send(String message); }

public class SMSNotifier implements Notifier {
    public void send(String message) { System.out.println("Type: SMS | message: " + message); }
}

public abstract class NotifierDecorator implements Notifier {
    protected Notifier notifier;	
    public NotifierDecorator(Notifier notifier) { this.notifier = notifier; }
    public void send(String message) { notifier.send(message); }
}

public class EmailDecorator extends NotifierDecorator {
    public EmailDecorator(Notifier notifier) { super(notifier); }
    @Override
    public void send(String message) {
        super.send(message);
        System.out.println("Type: EMAIL | message: " + message);
    }
}

public class Demo {
    public static void main(String[] args) {
        Notifier sms = new EmailDecorator(new SMSNotifier());
        sms.send("test message");
    }
}
