List<Employee> employees = new ArrayList<>();
employees.add(new Employee(3345,"john","male","HR",3.45));
employees.add(new Employee(3737,"Mark","male","Hardware",4.87));

Q1: Gender Count (Basic)

Grouping

Find the gender count from an employee collection.


Map<String, Long> genderDetails2 = employees.stream()
    .collect(Collectors.groupingBy(emp -> emp.getGender(), Collectors.counting()));

genderDetails2.forEach((k,v) -> System.out.println("gender : "+k+" count :"+v));

Q2: Gender Count (Specific Map Type)

Collectors

Find the gender count by explicitly specifying HashMap::new.


HashMap<String,Long> genderDetails = employees.stream()
    .collect(Collectors.groupingBy(
        emp -> emp.getGender(),
        HashMap::new,
        Collectors.counting()
    ));

Q3: Sort by Rating (Descending)

Sorting

Sort the collection based on employee rating in descending order.


employees.stream()
    .sorted(Comparator.comparingDouble(Employee::getRating).reversed())
    .forEach(emp -> System.out.println(emp.getName()+"|"+emp.getRating()));

Q4: Sort and Capture in Map

LinkedHashMap

Capture the sorted rating output in a LinkedHashMap to maintain insertion order.


LinkedHashMap<String,Double> empRating = employees.stream()
    .sorted(Comparator.comparingDouble(Employee::getRating).reversed())
    .collect(Collectors.toMap(
        emp -> emp.getName(),
        emp -> emp.getRating(),
        (a,b) -> a,
        LinkedHashMap::new
    ));

Q5: Department-wise Gender Count

Multi-Level Grouping

Group employees by department first, then count genders within those departments.


Map<String, Map<String, Long>> deptGenderCount = employees.stream()
    .collect(Collectors.groupingBy(
        Employee::getDepartment,
        Collectors.groupingBy(Employee::getGender, Collectors.counting())
    ));
